# Virtual Disturbance (browser build)

Play it here: https://xixftaaxix.github.io/virtual-disturbance-play/

This repository only holds the web build of the game (made with Unity), so it can be played in a browser. Chrome, Edge or
Firefox on a desktop or laptop work best. The first load is a large download; after that the browser keeps a copy.

## Controls

- **Click** the game once to let it take the mouse (and to start the sound). **Esc** gives the mouse back.
- **WASD** move, **Shift** sprint, **Space** jump, **C** crouch, **mouse** look around
- **E** pick up, sit in a desk-chair, open doors, and challenge a teacher or staff member to a battle
- **Q** flip a desk or table (or throw a weapon you're holding)
- **F** shove; hold it to push something around (**Shift** to push faster) and let go to shove it. Right up close to a
  teacher or staff member, **F** bites instead.
- **Left click** punch (or throw what you're carrying, or swing a weapon)
- **Right click** kick (or smash with a weapon)
- Sitting in a desk-chair: **A / D** swivel, **E** do the worksheet, **Space** stand up
- **R** restart the level

In a battle, pick a move with the arrow keys, number keys or mouse, then press **Space** (or E, or click) as the marker
crosses the middle of the timing bar.
